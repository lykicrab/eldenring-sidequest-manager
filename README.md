# 艾尔登法环支线管理

**[打开支线管理网页](https://lykicrab.github.io/eldenring-sidequest-manager/)**

首页按 NPC 展示各条支线的下一个未完成步骤。勾选完成后自动显示下一步；前置未完成时可点击查看具体条件。卡片可直接拖动排序，关联任务会按前置关系顺延，靠近页面边缘时自动滚动。

在“NPC 个人进度”中选择分支和结局、查看完整步骤，或撤销误勾；“收集表”记录道具取得情况。支持本体和黄金树幽影。

## 计划管理和备份

点击“新建计划”选择要安排的支线范围，也可导入旧版单个计划 JSON 或网页备份。已有计划支持复制和改名。清理浏览器数据或换设备前，请先导出计划备份。

进度只保存在当前设备、浏览器和网站地址的 localStorage 中。导入的文件只在浏览器内读取，导出也在本机完成，应用不上传计划进度或自动同步。仓库与网页发布文件不包含任何玩家的个人进度、迁移文件或备份。应用根据手动记录检查前置与分支，不读取游戏存档。

## 离线使用

第一次打开时保持联网，等页面显示“离线缓存已就绪”。之后可以在同一浏览器、同一网址下断网打开。更新发布后联网刷新；如果仍显示旧版，关闭该网站的所有标签再重新打开。
