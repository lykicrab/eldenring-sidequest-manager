# 艾尔登法环支线管理

从仓库页面来的话，可以点击这里直接使用：

**[打开支线管理网页](https://lykicrab.github.io/eldenring-sidequest-manager/)**

支线管理可以按 NPC 选择支线分支，生成可勾选的流程清单，并记录支线道具收集进度。勾选和选择会自动保存在当前浏览器。

## 离线使用

第一次打开网页时请保持联网，等页面显示“离线缓存已就绪”。之后在同一设备、同一浏览器和同一网址下，即使断网也可以重新打开使用。更换浏览器或设备、清理网站数据后，需要联网重新缓存。

## 进度与备份

周目进度保存在本机浏览器中，不会自动同步到其他设备。清理浏览器数据或换设备前，请点击网页上的“导出备份”；需要恢复时使用“导入计划”。
